# Speech Lounge — GitHub Pages website

## Files
- `index.html` — website homepage
- `assets/images/` — six locally stored website images

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `speech-lounge-website`).
2. Upload the contents of this folder to the repository's root. The `index.html` file must be at the root, not inside another folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish, then open the URL shown in the Pages settings.

## Notes
- This is a static website. The Tailwind CSS, Google Fonts and Material Symbols resources are loaded from their public CDNs, so visitors need an internet connection for those assets.
- WhatsApp enquiry links are included in the page.
- Before publishing, verify the clinician's contact number, service details, fees, locations and all enquiry links.
- For a custom domain, add it in **Settings → Pages → Custom domain**, then configure the DNS records at your domain provider. Keep any existing email-related DNS records.
